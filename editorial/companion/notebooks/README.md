# Optional Advanced Numerical Explorations

This directory is reserved for self-contained, documented Python notebooks that complement the browser-native physics laboratories. They may support exact diagonalization, convergence studies, semiclassical approximations, scattering calculations, Berry-curvature integration, and quantum-learning examples.

**Current status:** design placeholder; no notebooks are published.

Any notebook added here should state its physics assumptions and link to a named lab and existing `chapters/chNN/...tex` source. Include reproducible example parameters, figures labeled in English, independent analytic or numerical verification and an explanation of numerical limitations. Essential student learning must remain possible from the web companion without Python installation.
