# Reproducible quantum-machine-learning illustrations

The four vector PDF plots included in Chapter 9 are generated by running:

```bash
python -m pip install numpy matplotlib
python scripts/generate_qml_figures.py
```

All inputs and model definitions are recorded in that script; its fixed pseudorandom seed is `20261016`. No external data or quantum SDK is used.

1. `parameter_shift.pdf`: exact expectation `cos(theta)`, measured at offsets ±pi/2 from theta0 = 0.48.
2. `one_qubit_training.pdf`: full-batch gradient descent for `cos(x+theta)` on 31 equally spaced data, 35 steps, exact simulator, no finite-shot noise.
3. `one_qubit_kernel.pdf`: exact fidelity kernel `cos²[(xi-xj)/2]` on a 17-input grid. Computed eigenvalues include tiny machine-precision negative roundoff only.
4. `global_projector_gradients.pdf`: **model-specific** gradient-variance decay, from Haar-random pure states with a global zero-state projector, comparing 1,800 samples per qubit count to the exact identity `Var[f'(0)] = 1/[2d(d+1)]`, `d=2^n`.

PDFs are included in the textbook as vector illustrations. PNGs are optional review images and are excluded from the committed artifacts.
