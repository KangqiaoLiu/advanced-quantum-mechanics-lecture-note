**Scientific editorial notes:** [`editorial/CHAPTER01_TRANSLATION_LOG.md`](../../editorial/CHAPTER01_TRANSLATION_LOG.md). Revisions to content should be made in separate, traceable commits after approval; this version is the source-faithful translation baseline.
