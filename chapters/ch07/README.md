# Chapter 7 — Bosons, Fermions, and Second Quantization

**Instructor-directed replacement** of the original source-PDF-based Chapter 7. The new proof sequence closely follows the instructor's actual lecture handouts.

- `01_bosons.tex`: `1.3 Bosons.pdf` (6 handwritten pages): symmetrized occupation basis, Bose Fock space, vacuum, creation and annihilation, commutator algebra, number operator, one-body and pair operators.
- `02_fermions.tex`: `1.4 Fermions.pdf` (5 handwritten pages): Slater determinant, Pauli principle, fixed orbital order, fermion creation/annihilation with the parity sign, CAR proof, and the shared one- and two-body operator Hamiltonian.

One- and two-body matrix elements use **unsymmetrized** orbital integrals and the operator ordering $a_i^\dagger a_j^\dagger a_l a_k$. The factor $1/2$ in the interaction Hamiltonian is the original pair-counting factor. The canonical operator $\hat{\mathcal O}$ for a generic additive observable is used instead of the handwritten $\hat T$, reserving $\hat T$ for the scattering transition operator elsewhere in the book. All symbols are defined locally, without increasing the one-page List of Notation.

The instructor's source PDFs are not committed to the repository. The pre-replacement Chinese-source translation remains on the preserved Git branch.
